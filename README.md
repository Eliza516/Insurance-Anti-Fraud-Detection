# Insurance-Anti-Fraud-Detection

Build classification models (KNN, Logistic Regression, Naive Bayes, Decision Tree, Random Forest) for insurance fraud detection.

● Data: https://www.kaggle.com/code/buntyshah/insurance-fraud-claims-detection
● Train/test split: 80/20.
● Plot the decision tree to explain its predictions.
● Feature importance: identify the top 5 features.
● Optional: apply feature selection to reduce dimensionality.
